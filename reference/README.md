# Structural Scheme

Генератор структурных схем для АСУ ТП. Приложение позволяет настраивать операторные станции, серверные
стойки, сетевые шкафы и шкафы автоматики, а затем экспортировать результат в SVG, PNG, JPG или Draw.io.

Приложение — **один файл `index.html`**: открывается двойным щелчком, не требует установки, сборки в браузере
и доступа к интернету (библиотеки и стили встроены в файл).

## Запуск

1. Откройте `index.html` в современном браузере.
2. Настройте проект на вкладках **Проект**, **Операторная**, **Серверная** и **Шкафы автоматики**.
3. Используйте кнопки экспорта над предпросмотром схемы: **SVG**, **PNG**, **JPG**, **Draw.io**.

На вкладке **Шкафы автоматики** можно при необходимости включить **RS-485 между** и выбрать второй шкаф.
Связь появится на схеме и во всех форматах экспорта.

### Построение линий

Восстановлена трассировка из `index backup.html`: выходы распределяются по положению целей,
входы — по порядку подходящих линий, обходы рядов — по ближайшим межколоночным зазорам.
Эта геометрия используется и в предпросмотре, и во всех форматах экспорта.
Ограничение backup: в насыщенных многострочных схемах вертикальные участки разных связей
могут накладываться. Три существующих теста в `tests/routing.test.js` обнаруживают эти
наложения и пока не проходят; проверки сохранены без ослабления.

При необходимости страницу можно открыть через локальный сервер:

```bash
npm start   # http://localhost:8000/
```

## Сохранение проекта

- Все изменения автоматически сохраняются в браузере и восстанавливаются при следующем открытии страницы.
- На вкладке **Проект** кнопка **Сохранить проект** скачивает файл `.json`, а **Открыть проект** загружает его
  обратно — так проект можно перенести на другой компьютер или передать коллеге.
- **Начать заново** заменяет текущий проект демонстрационным примером (после подтверждения).

## Разработка

Требуется Node.js 20 или новее. `index.html` — **собранный файл**: правьте исходники в `src/` и пересобирайте.

```bash
npm ci            # зависимости для тестов, сборки страницы и CSS
npm test          # все тесты, включая сквозные в jsdom и проверку свежести сборки
npm run build     # собрать index.html из src/ (обязательно после правок)
npm run build:css # пересобрать src/styles.css после изменения Tailwind-классов
npm run vendor    # обновить vendor/ после смены версий react / react-dom / htm
npm start         # локальный сервер: http://localhost:8000/
```

Устройство проекта и правила внесения изменений описаны в [AGENTS.md](AGENTS.md).
